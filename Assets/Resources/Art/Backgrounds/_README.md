# 背景图 (Backgrounds)

## 这个目录放什么
游戏对局界面的全屏背景图。运行时由 `SceneBootstrap` 加载到 `BackgroundCanvas`,铺满全屏。

## 文件命名
- `bg_game.png` — 主对局背景(已有)
- 其它备用风格:`bg_game_dark.png`、`bg_event_winter.png` 等

## 推荐尺寸
- **1080×1920** 像素(竖屏标准)
- 重要内容(花纹中心、装饰)建议集中在中间 **1080×1620** 区域,上下各 150 像素是"安全裁剪区",iPad/超宽屏可能被裁掉
- 格式:PNG,可带透明通道但不强制

## ⚠️ 已知问题(2026.5.13 重构期发现)
当前 `bg_game.png` 在背景里**画死了 8×8 棋盘格底盘**。
分辨率切到非 9:16(iPhone 12 / iPad / 16:9 等)时,实际可放置格子 ≠ 背景图棋盘格,玩家拖方块吸附会和背景对不上。

**建议处理**: 出一张**纯背景**(不画任何棋盘格),棋盘格由代码动态画。详见 `设计文档/会议内容/2026.5.13 美术资源待调整清单.md`。

## 替换流程
1. 直接覆盖 `bg_game.png` 即可,不需要进 Unity
2. Unity 自动检测变更并刷新
