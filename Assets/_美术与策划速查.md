# 美术与策划速查 (1 屏指引)

> 这份 200 字的速查给美术/策划同学。**一句话:绝大多数事情只改一个 .asset,不进代码**。

## 入口
**Unity 顶部菜单 → BlockPuzzle → 游戏配置中心**

会自动选中 `Assets/Resources/Configs/GameConfig.asset`。这是整个游戏的总入口,Inspector 里会看到所有子配置 + 每个右侧的"打开"按钮,直接点跳过去。

## 我想改 X → 改这个

| 我想... | 改这个文件 |
|---|---|
| 调棋盘大小 / 上下留白 | `LayoutConfig.asset`(顶部留白比例 / 底部留白比例) |
| 改计分公式 | `ScoreConfig.asset` |
| 加方块新形状 / 调权重 | 菜单 `BlockPuzzle/方块形状配置器` |
| 换消除音效 / 放置音效 | `AudioLibrary.asset` 加 Cue → `AudioBindings.asset` 选事件绑定 |
| 加消除震屏 / 放置粒子 | `FxLibrary.asset` 加一项,选事件类型,拖入特效 Prefab |
| 改飘字图集 / 颜色 / 文字格式 | `FloatingTextLibrary.asset` |
| 换主背景图 | 直接覆盖 `Assets/Resources/Art/Backgrounds/bg_game.png` |
| 改 UI 配色 / SafeArea 策略 | `UIThemeConfig.asset` |
| 关掉所有震动 / 音效 | `GameplayTuning.asset` |
| 改 GameOver 弹窗布局 | `Assets/Prefabs/UI/GameOverPanel.prefab` |

## 资源放在哪

`Assets/Resources/Art/各子目录/_README.md` 里都写了说明。

- `Backgrounds/` — 背景图
- `Blocks/` — 方块切图
- `Board/` — 棋盘格底色
- `UI/` — 按钮、面板、图标
- `Fx/` — 特效粒子(用到 FxLibrary 的 Prefab,可放 `Assets/Prefabs/Fx/`)

## 美术做新特效流程

1. 在 Unity 里搭一个粒子/动画 Prefab,拖到 `Assets/Prefabs/Fx/`
2. 打开 `FxLibrary.asset`,展开 entries,点 + 加一项
3. 在新条目里选"事件类型"(消除/放置/Combo 等),把 Prefab 拖到 `effectPrefab` 字段
4. 调 `lifetime`(存活秒数)、`shakeAmplitude`(震屏强度)等
5. Play 一局看效果,完成

## 策划新增飘字格式流程

1. 打开 `FloatingTextLibrary.asset`,加一条模板
2. 选事件、选渲染方式(数字图集 / TMP 字体)
3. 写 `textFormat`,占位符可用 `{score}` `{multiplier}` `{lines}`
4. 调颜色、飘动方向、生命周期
5. 完成

## 任何参数改完不生效?
- **Play 模式中调好后,菜单 `BlockPuzzle/重新应用游戏配置` 或快捷键 `Ctrl/Cmd+Shift+R`**(布局/主题/形状库的改动会立即重摆棋盘格)
- 重启 Play(部分参数只在场景启动时读)
- 看 Console 有没有红字提示("配置项缺失"等都会用中文提示)
- 找开发同学

## 补充

如果某条事件你不确定它什么时候触发,看这个枚举(在 `Assets/Scripts/Core/GameplayEvents.cs`):

- 方块放置成功 / 方块消除 / Combo 触发 / Combo 中断 / 新最高分 / 一局开始 / 一局结束 / 按钮点击 / 无可放置警告
